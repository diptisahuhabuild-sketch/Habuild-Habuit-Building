📋 Golden Rules — Remember Always

🔶 Pause Handling

  • Member says pause = process it. Don't re-pitch.
  • Confirm exact dates + number of days
  • Fill DM form EVERY time
  • Share pause instructions after processing
  • For travel — offer 24hr access first (if applicable)

🔷 Communication

  • Match member's language ALWAYS
  • Health concern = empathy FIRST, then solution
  • Use "we" not "I"
  • Acknowledge small things ("No worries")
  • Don't copy-paste ChatGPT directly

🔶 Before Responding

  • SCROLL UP — read the full chat history
  • Count all questions in the message
  • Answer EVERY question — not just the first one
  • Verify dates, subscription details in CRM
  • Check: Free vs Paid member? International?

🔷 Technical / Link Issues

  • Apologize + ask for screenshot
  • NEVER close until issue is confirmed resolved
  • Repeated issue = escalate to concerned team
  • International members = already have 24hr access
  • Know the difference: free vs paid features
